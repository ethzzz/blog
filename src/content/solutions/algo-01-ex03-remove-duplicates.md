## 题目

给你一个 **非严格递增** 排列的数组 `nums`，请你 **原地** 删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。元素的相对顺序应保持一致。

判题规则：不需要真的删除尾部元素，只要把去重后的结果写到数组前 `k` 个位置，返回 `k` 即可。

```
输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5, nums = [0,1,2,3,4,...]
```

## 思路：一个指针读，一个指针写

这是快慢指针最经典的形态，理解它的方式是给两个指针**分工**：

- `fast`：**读指针**，一路向右扫描，负责"探索"下一个还没确认的元素
- `slow`：**写指针**，指向下一个可以写入的位置，它的左侧（不含自己）就是"已经确认去重完毕"的成果区

因为数组有序，重复元素必然相邻。所以判断规则极其简单：**`nums[fast]` 和它前一个不一样，它就是新元素**，写到 `slow` 位置并把 `slow` 推进一格。

```
nums = [0,0,1,1,1,2,2,3,3,4]
        s
        f

fast=0: slow=1 起步（第 0 个元素一定保留）
fast=1: nums[1]===nums[0]  → 跳过
fast=2: nums[2]=1 !== 0    → nums[1]=1, slow=2
fast=5: nums[5]=2 !== 1    → nums[2]=2, slow=3
fast=7: nums[7]=3 !== 2    → nums[3]=3, slow=4
fast=9: nums[9]=4 !== 3    → nums[4]=4, slow=5
返回 5
```

## 代码

```ts
function removeDuplicates(nums: number[]): number {
	if (nums.length === 0) return 0;

	let slow = 1;
	for (let fast = 1; fast < nums.length; fast++) {
		if (nums[fast] !== nums[fast - 1]) {
			nums[slow] = nums[fast];
			slow++;
		}
	}

	return slow;
}
```

`slow` 从 1 开始而不是 0，是因为第 0 个元素无论怎样都该保留——它没有"前一个"可比。

## 复杂度

- 时间 **O(n)**：`fast` 从头扫到尾，每步 O(1)
- 空间 **O(1)**：原地写，没有额外数组

## 复盘

这个"读写分离"的写法是一个**可以复用的万能模板**，不止用于去重。同一套骨架能解：

- 第 27 题「移除元素」：把条件从"不等于前一个"改成"不等于 val"
- 第 283 题「移动零」：先按非零条件写一遍，再把 `slow` 之后的补零
- 第 80 题「删除有序数组中的重复项 II」：允许保留两次，把比较对象从 `nums[fast-1]` 改成 `nums[slow-2]`

最后这条变体值得单独想一下：为什么是跟 `nums[slow - 2]` 比而不是 `nums[fast - 2]`？因为 `slow - 2` 才是"成果区里倒数第二个已确认的值"，用 `fast` 的话会被跳过的重复元素污染判断。**跟谁比，取决于你要保证的不变量是什么** —— 这是把模板用对的关键。
