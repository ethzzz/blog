## 1. 状态定义三步走

拿到 DP 题，按顺序回答三个问题：

1. **`dp[i]` 的含义**：一句话说清——"到第 i 个位置 / 用前 i 个元素，最优答案是什么"；
2. **转移方程**：`dp[i]` 怎么由更小的子问题算出来；
3. **初值与遍历顺序**：哪些位置没有"更小的子问题"，从哪开始填表。

一句话判断是不是 DP：**当前最优能否由"更小规模的最优"推出？** 能——DP；不能——回溯、贪心或别的。

### 1.1 三类信号词

| 题目问法 | 转移写法 | 例子 |
| --- | --- | --- |
| **最值**（最多/最少/最长） | `max` / `min` | 最大子数组和、零钱兑换 |
| **方案数**（多少种） | **累加** | 爬楼梯、零钱兑换 II |
| **可行性**（能不能） | `or` / `boolean` | 分割等和子集 |

如果题目问"**所有**方案是什么"——那是回溯，不是 DP。

### 1.2 从记忆化递归到填表

以爬楼梯（70 题）为例，先理解状态依赖：

```ts
// 记忆化递归：dp 的"来源"形态
function climb(n: number, memo = new Map<number, number>()): number {
  if (n <= 2) return n;
  if (memo.has(n)) return memo.get(n)!;
  const ways = climb(n - 1, memo) + climb(n - 2, memo);
  memo.set(n, ways);
  return ways;
}
```

再改写成自底向上的滚动变量版：

```ts
function climbStairs(n: number): number {
  if (n <= 2) return n;
  let prev = 1;
  let cur = 2;
  for (let i = 3; i <= n; i++) {
    [prev, cur] = [cur, cur + prev]; // 只依赖前两个 → 两个变量足够
  }
  return cur;
}
```

**面试节奏**：先用递归版说明"状态依赖"，再用填表版展示空间优化，两分钟讲完。

变体：**使用最小花费爬楼梯**（746 题），"到达"的是第 i 阶，初值有两项：

```ts
function minCostClimbingStairs(cost: number[]): number {
  const n = cost.length;
  const dp = new Array(n + 1).fill(0); // dp[i]：到达第 i 阶的最小花费
  for (let i = 2; i <= n; i++) {
    dp[i] = Math.min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
  }
  return dp[n];
}
```

`dp[0] = dp[1] = 0`：从第 0 或第 1 阶出发都不花钱，这是本题唯一的"反直觉"初值。

## 2. 打家劫舍：偷/不偷两分支

**198 题**：不能偷相邻两家，求最大金额。

1. `dp[i]` = 考虑前 i+1 间房的最大金额；
2. 转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`——不偷 vs 偷；
3. 初值：`dp[0] = nums[0]`，`dp[1] = max(nums[0], nums[1])`。

```ts
function rob(nums: number[]): number {
  const n = nums.length;
  if (n === 1) return nums[0];

  const dp = new Array(n);
  dp[0] = nums[0];
  dp[1] = Math.max(nums[0], nums[1]);
  for (let i = 2; i < n; i++) {
    dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
  }
  return dp[n - 1];
}

// O(1) 空间版：只保留前两间房的答案
function robRolling(nums: number[]): number {
  let prev2 = 0; // dp[i-2]
  let prev1 = 0; // dp[i-1]
  for (const x of nums) {
    const cur = Math.max(prev1, prev2 + x);
    prev2 = prev1;
    prev1 = cur;
  }
  return prev1;
}
```

`prev2`/`prev1` 同时充当"空数组"的初值，所以不需要特判 `n === 1`——**滚动变量版往往比数组版更少边界**。

### 2.1 环形（213 题）与树形（337 题）

环形：首尾相邻，所以首尾不能同时偷。拆成两个线性问题：

```ts
const robRange = (nums: number[], l: number, r: number): number => {
  let prev2 = 0;
  let prev1 = 0;
  for (let i = l; i <= r; i++) {
    const cur = Math.max(prev1, prev2 + nums[i]);
    prev2 = prev1;
    prev1 = cur;
  }
  return prev1;
};

function robCircle(nums: number[]): number {
  if (nums.length === 1) return nums[0];
  return Math.max(
    robRange(nums, 0, nums.length - 2), // 不偷最后一家
    robRange(nums, 1, nums.length - 1), // 不偷第一家
  );
}
```

树形（337 题）：递归返回二元组 `[不偷当前, 偷当前]`，用孩子的两组状态拼自己的两组：

```ts
function robTree(root: TreeNode | null): number {
  const dfs = (n: TreeNode | null): [number, number] => {
    if (!n) return [0, 0];
    const [l0, l1] = dfs(n.left);
    const [r0, r1] = dfs(n.right);
    return [
      Math.max(l0, l1) + Math.max(r0, r1), // 不偷当前：孩子随意
      n.val + l0 + r0,                    // 偷当前：孩子必须不偷
    ];
  };
  const [skip, take] = dfs(root);
  return Math.max(skip, take);
}
```

## 3. 0/1 背包与完全背包：遍历方向决定一切

这是验收清单里必问、但很多入门文章跳过的一节。

### 3.1 0/1 背包：每个物品最多一次

```ts
// weights/values 一一对应，容量 cap，求最大价值
function knapsack01(weights: number[], values: number[], cap: number): number {
  const dp = new Array(cap + 1).fill(0); // dp[c]：容量 c 时的最大价值

  for (let i = 0; i < weights.length; i++) {
    for (let c = cap; c >= weights[i]; c--) {
      // 倒序！dp[c] 依赖"上一轮"的 dp[c-w]
      dp[c] = Math.max(dp[c], dp[c - weights[i]] + values[i]);
    }
  }
  return dp[cap];
}
```

**为什么必须倒序**：一维数组压缩掉"物品"这一维后，`dp[c]` 的转移要用到 `dp[c - w]`。如果正序遍历，`dp[c - w]` 可能**已经被当前物品更新过**，等于同一件物品用了两次——那就变成完全背包了。

倒序遍历保证：读取 `dp[c - w]` 时，它还是"上一件物品"的状态。

### 3.2 完全背包：每个物品无限次

```ts
function knapsackComplete(weights: number[], values: number[], cap: number): number {
  const dp = new Array(cap + 1).fill(0);
  for (let i = 0; i < weights.length; i++) {
    for (let c = weights[i]; c <= cap; c++) {
      // 正序！允许重复使用当前物品
      dp[c] = Math.max(dp[c], dp[c - weights[i]] + values[i]);
    }
  }
  return dp[cap];
}
```

一句话记住：**0/1 背包倒序，完全背包正序**。面试只问这一句，但你要能解释"为什么"。

## 4. 零钱兑换：最少硬币与组合计数

### 4.1 最少硬币数（322 题）

1. `dp[i]` = 凑出金额 i 的最少硬币数；
2. 转移：对每种硬币，`dp[i] = min(dp[i], dp[i - coin] + 1)`；
3. 初值：`dp[0] = 0`，其余 `Infinity`。

```ts
function coinChange(coins: number[], amount: number): number {
  const dp = new Array(amount + 1).fill(Infinity);
  dp[0] = 0;

  for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
      if (i >= coin && dp[i - coin] !== Infinity) {
        dp[i] = Math.min(dp[i], dp[i - coin] + 1);
      }
    }
  }
  return dp[amount] === Infinity ? -1 : dp[amount];
}
```

`Infinity` 哨兵是"求最小设最大"的口诀；但参与运算前要排除，否则 `Infinity + 1` 会污染答案。

### 4.2 组合数（518 题）：内外层顺序敏感

```ts
function change(amount: number, coins: number[]): number {
  const dp = new Array(amount + 1).fill(0);
  dp[0] = 1; // 凑 0 元有 1 种方式：什么都不选

  for (const coin of coins) {        // 外层：物品
    for (let a = coin; a <= amount; a++) { // 内层：容量，正序
      dp[a] += dp[a - coin];
    }
  }
  return dp[amount];
}
```

如果**交换内外层**（金额外层、硬币内层），计数的是**排列**而不是组合，`amount = 3, coins = [1,2]` 会把 `1+2` 和 `2+1` 算两次。

一句话解释：**外层硬币保证"每种硬币只被考虑一轮"**，所以结果的顺序无关。

## 5. 最大子数组和：滚动 DP

```ts
function maxSubArray(nums: number[]): number {
  let cur = nums[0];
  let ans = nums[0];
  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]); // 带上前面 or 重新开始
    ans = Math.max(ans, cur);
  }
  return ans;
}
```

直觉：**前面的累积和如果拖后腿（负数），就断开重开**。

### 5.1 为什么这题不能贪心

贪心会错的反例：`coins = [1, 3, 4]`，`amount = 6`。贪心每次拿最大面额：`4 + 1 + 1 = 3` 枚；最优是 `3 + 3 = 2` 枚。

**贪心只看局部最优，不做"后悔"**；DP 通过枚举状态保留所有可能。这道反例面试常用来区分"知道 DP"和"只会背公式"。

## 6. 常见坑

| 现象 | 根因 | 解法 |
| --- | --- | --- |
| 0/1 背包算成"无限用" | 容量正序遍历 | 0/1 倒序，完全背包正序 |
| 组合数算成排列数 | 金额在外层、硬币在内层 | 硬币外层、金额内层 |
| 零钱兑换出现 `Infinity+1` | 没排除不可达状态 | 转移前判 `!== Infinity` |
| 最大子数组和全负数答案错 | 初始化为 0 | `ans = nums[0]` |
| 打家劫舍空数组崩 | 没处理 `n === 0/1` | 用滚动变量版，天然免特判 |
| 环形打家劫舍漏解 | 只跑了一个区间 | 首尾各排除一次，取 max |
| 爬楼梯初值写反 | `dp[0]` 定义不清 | 明确"到达第 i 阶"还是"走 i 步" |
| 说成 O(2ⁿ) | 没提记忆化/填表 | DP 后是 O(n) / O(n·cap) |

## 7. 小结

- 三步走：状态含义 → 转移方程 → 初值与顺序。
- 三类信号：最值 `max/min`、方案数累加、可行性布尔。
- 打家劫舍：偷/不偷；环形拆线性；树形返回二元组。
- 背包：0/1 倒序、完全正序；组合计数硬币在外层。
- 能滚动就滚动，O(1) 空间是标配加分项。
