> [!NOTE]
> DP 的门槛不在聪明，在**套路**。所有入门题都走同一套流程：定义状态 → 找转移方程 → 定初始化 → 定遍历顺序。这篇把四步变成肌肉记忆。

## 1. 状态定义三步走

拿到 DP 题，按顺序回答三个问题：

1. **dp[i] 的含义是什么？**（一句话说清：到第 i 个位置/前 i 个元素，最优答案是什么）
2. **dp[i] 怎么由更小的子问题算出来？**（转移方程）
3. **初始值和遍历顺序？**（哪些位置没有"更小的子问题"，从哪开始填表）

一句话判断是不是 DP 题：**当前的最优解能否由"更小规模的最优解"推出？** 能——DP；不能——可能该回溯或贪心。

两个高频的"DP 信号词"帮你快速识别：题目问**最值**（最长、最少、最大、最少操作）且**后面的决策依赖前面的结果**，比如"不能偷相邻两家"——DP 的概率极大；题目问**方案数**（多少种走法、多少种组合），也是 DP 的标志，对应转移从 `max/min` 换成 `+`。反过来，问"所有方案是什么"（枚举）就是回溯，问"贪心选择是否安全"才考虑贪心。面试前两分钟完成这个分诊，方向就不会错。

**从记忆化递归开始理解**是最平滑的路径。以爬楼梯（70 题）为例：

```ts
// 递归 + 备忘录：dp 的"来源"形态
const memo = new Map<number, number>();
function climb(n: number): number {
  if (n <= 2) return n;
  if (memo.has(n)) return memo.get(n)!;
  const ways = climb(n - 1) + climb(n - 2);   // 到第 n 阶 = 从 n-1 跨 1 步 或 n-2 跨 2 步
  memo.set(n, ways);
  return ways;
}
```

再改写成自底向上的填表版：

```ts
function climbStairs(n: number): number {
  if (n <= 2) return n;
  let prev = 1, cur = 2;
  for (let i = 3; i <= n; i++) {
    [prev, cur] = [cur, cur + prev];    // 只依赖前两个 => 滚动变量省数组
  }
  return cur;
}
```

面试建议：先给递归版证明你理解了"状态依赖"，再给填表版证明你会优化——两分钟讲完，层次分明。

## 2. 打家劫舍：相邻不相邻的经典依赖

**198 题**：一排房子，不能偷相邻两家，求最大金额。

**三步走**：

1. dp[i] = 考虑前 i+1 间房的最大金额。
2. 转移：第 i 家**偷或不偷**——偷则 `dp[i-2] + nums[i]`（隔壁必不能偷），不偷则 `dp[i-1]`，取大者。
3. 初始化：`dp[0] = nums[0]`，`dp[1] = max(nums[0], nums[1])`；从 i=2 正序遍历。

```ts
function rob(nums: number[]): number {
  const n = nums.length;
  if (n === 1) return nums[0];
  const dp: number[] = new Array(n);
  dp[0] = nums[0];
  dp[1] = Math.max(nums[0], nums[1]);
  for (let i = 2; i < n; i++) {
    dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);   // 不偷 vs 偷
  }
  return dp[n - 1];
}
```

逐行讲：转移方程里"偷/不偷"两个分支，就是这题的**状态设计核心**——不确定就"枚举所有可能的决策，各取最优"。这题的环形版（213 题，首尾相邻）追问思路：拆成"不偷第一家"和"不偷最后一家"两个线性问题分别跑 rob，取 max。面试答出"环形拆线性"四个字就够了。

还有一个树形版（337 题，打家劫舍 III，房子排成二叉树），是"树形 DP"的入门题：递归函数返回一个二元组 `[偷当前的最大收益, 不偷当前的最大收益]`，每个节点用孩子的两组状态拼出自己的两组状态。它能答出来的前提是第 06 篇的"递归函数返回值携带信息"已经吃透——这也是我把树篇排在 DP 篇之前的原因之一。

## 3. 零钱兑换：完全背包的入门形态

**322 题**：无限枚面额的硬币，凑出 amount 的最少硬币数。

**三步走**：

1. `dp[i]` = 凑出金额 i 的最少硬币数。
2. 转移：对每种硬币 `coin`，`dp[i] = min(dp[i], dp[i - coin] + 1)`——用一枚 coin，剩下金额交给子问题。
3. 初始化：`dp[0] = 0`（凑 0 元要 0 枚），其余设为 `Infinity` 表示"暂时凑不出"；正序遍历金额。

```ts
function coinChange(coins: number[], amount: number): number {
  const dp: number[] = new Array(amount + 1).fill(Infinity);
  dp[0] = 0;
  for (let i = 1; i <= amount; i++) {        // 遍历金额
    for (const coin of coins) {              // 遍历决策
      if (i >= coin && dp[i - coin] !== Infinity) {
        dp[i] = Math.min(dp[i], dp[i - coin] + 1);
      }
    }
  }
  return dp[amount] === Infinity ? -1 : dp[amount];
}
```

逐行讲：`Infinity` 哨兵是关键——表示"该金额无法凑出"，参与 min 之前必须排除，否则 `Infinity + 1` 污染答案。**初始化为"求最小设最大、求最大设最小"**，是 DP 初始化的通用口诀。

**零钱兑换 II**（518 题，追问版）从"最少枚数"变成"组合数"，转移从 `min` 改成累加 `dp[i] += dp[i - coin]`，且**外层必须遍历硬币、内层遍历金额**——反过来会重复计数排列。面试官问"为什么内外顺序影响结果"，答案：外层硬币保证每种硬币只被"考虑一轮"，计数的是组合而非排列。

## 4. 最大子数组和：一维 DP 的贪心变体

**53 题**（超高频）：连续子数组的最大和。

```ts
function maxSubArray(nums: number[]): number {
  let cur = nums[0], ans = nums[0];
  for (let i = 1; i < nums.length; i++) {
    // dp[i] = max(nums[i], dp[i-1] + nums[i])：带上前面 or 重新开始
    cur = Math.max(nums[i], cur + nums[i]);
    ans = Math.max(ans, cur);
  }
  return ans;
}
```

转移的直觉表述：**前面的累积和如果拖后腿（负数），就果断断开重开**。这题还展示了 DP 的一类通用优化——`dp[i]` 只依赖 `dp[i-1]` 时，用一个变量替代整个数组，空间 O(n) → O(1)。爬楼梯、打家劫舍同理，面试答完 O(n) 主动补一句"可以滚动优化到 O(1)"，基本是标配动作。

## 小结

- DP 三步走：一句话定义状态 → 转移方程 → 初始化与遍历顺序。
- 识别口诀：当前最优能否由更小规模的最优推出。
- 打家劫舍：偷/不偷两分支取大；环形拆线性。
- 零钱兑换：求最小初始化 Infinity；组合数题内外层顺序敏感。
- 滚动优化：只依赖上一步时用变量省数组，O(1) 空间。
