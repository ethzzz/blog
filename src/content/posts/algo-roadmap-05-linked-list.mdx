## 1. 先准备测试工具：数组 ↔ 链表

链表题最麻烦的是"怎么在 Console 里验"。两个十行工具函数就能让你像操作数组一样测链表：

```ts
interface ListNode {
  val: number;
  next: ListNode | null;
}

// 数组 → 链表（从右往左 reduce，把后一个当 next）
const fromArray = (arr: number[]): ListNode | null =>
  arr.reduceRight<ListNode | null>((next, val) => ({ val, next }), null);

// 链表 → 数组（方便 console.log 和断言）
function toArray(head: ListNode | null): number[] {
  const out: number[] = [];
  for (let p = head; p; p = p.next) out.push(p.val);
  return out;
}

// 用法
const head = fromArray([1, 2, 3, 4, 5]);
console.log(toArray(reverseList(head))); // [5,4,3,2,1]
```

> 面试时也可以主动说"我会用数组辅助测试链表"，这是很实在的工程习惯。

## 2. 虚拟头结点：让头节点不再是特例

链表题一半的错误来自"头节点可能被删或被换"导致的边界特判。**虚拟头结点**（dummy）一招解决：

```ts
function removeElements(head: ListNode | null, val: number): ListNode | null {
  const dummy: ListNode = { val: 0, next: head };
  let cur: ListNode = dummy;
  while (cur.next) {
    if (cur.next.val === val) cur.next = cur.next.next; // 跳过目标节点
    else cur = cur.next;
  }
  return dummy.next; // 真正的头可能已被删，必须从 dummy.next 取
}
```

对比不用 dummy 的版本：删头节点要单独写 `while (head && head.val === val) head = head.next;`，多一段几乎一样的逻辑。**所有"可能动头"的题，先造 dummy。**

### 2.1 删除倒数第 N 个节点

```ts
function removeNthFromEnd(head: ListNode | null, n: number): ListNode | null {
  const dummy: ListNode = { val: 0, next: head };
  let fast: ListNode = dummy;
  let slow: ListNode = dummy;

  for (let i = 0; i < n; i++) fast = fast.next!; // fast 先走 n 步
  while (fast.next) {                            // fast 停在尾节点时停下
    fast = fast.next;
    slow = slow.next!;
  }
  slow.next = slow.next!.next;                   // slow 正好是待删节点的前驱
  return dummy.next;
}
```

**差一细节**是本题唯一的坑：循环条件是 `while (fast.next)` 而不是 `while (fast)`。目标是让 `slow` 停在**前驱**，因为删除需要前驱；如果 `fast` 走到 `null`，`slow` 会停在待删节点本身，就无法删除它了。

## 3. 反转全家桶

### 3.1 迭代版：存、反、进、进

```ts
function reverseList(head: ListNode | null): ListNode | null {
  let prev: ListNode | null = null;
  let cur = head;
  while (cur) {
    const next = cur.next; // 1. 先存后继，防止断链
    cur.next = prev;       // 2. 反指
    prev = cur;            // 3. prev 前进
    cur = next;            // 4. cur 前进
  }
  return prev;             // prev 即新头
}
```

三指针各司其职：`prev` 是已反转部分的头，`cur` 是待处理节点，`next` 只是暂存。**空间 O(1)**。

### 3.2 递归版：先反转后面，再处理自己

```ts
function reverseListRec(head: ListNode | null): ListNode | null {
  if (!head || !head.next) return head;    // 终止：空或单节点
  const newHead = reverseListRec(head.next); // 反转后面，返回新头
  head.next.next = head;                   // 让后继指回自己
  head.next = null;                        // 自己变成尾
  return newHead;
}
```

递归版的理解关键：**不要试图在脑子里展开整个调用栈**，只相信"递归已经把 `head.next` 之后的链反转好了，并返回了新头"。空间 O(n)（调用栈）。

两版都要会，因为面试官常追问："递归版的空间复杂度是多少？能不能改成迭代？"

### 3.3 区间反转：头插法

```ts
function reverseBetween(head: ListNode | null, m: number, n: number): ListNode | null {
  const dummy: ListNode = { val: 0, next: head };
  let pre: ListNode = dummy;
  for (let i = 0; i < m - 1; i++) pre = pre.next!; // pre：区间前驱

  const start = pre.next!;  // 区间第一个，反转后变成区间尾
  let cur = start.next;

  for (let i = 0; i < n - m; i++) {
    start.next = cur!.next; // 把 cur 从原位摘下来
    cur!.next = pre.next;   // 插到 pre 后面（头插）
    pre.next = cur;
    cur = start.next;       // 下一个待搬的节点
  }
  return dummy.next;
}
```

`start` 始终不动，它后面的节点被逐个"摘下来插到 `pre` 之后"。这个写法比"整段反转再拼接"少一次遍历，也更能体现指针掌控力。

### 3.4 两两交换

```ts
function swapPairs(head: ListNode | null): ListNode | null {
  const dummy: ListNode = { val: 0, next: head };
  let pre: ListNode = dummy;
  while (pre.next && pre.next.next) {
    const a = pre.next;
    const b = a.next;
    a.next = b.next;
    b.next = a;
    pre.next = b;
    pre = a; // a 现在是这一对的尾
  }
  return dummy.next;
}
```

结构与 3.3 相同：`pre` 是"上一段的尾"，每轮重排两个节点后把 `pre` 移到新的尾部。

## 4. 合并：两条链与 K 条链

### 4.1 合并两个有序链表

```ts
function mergeTwoLists(l1: ListNode | null, l2: ListNode | null): ListNode | null {
  const dummy: ListNode = { val: 0, next: null };
  let tail = dummy;

  while (l1 && l2) {
    if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
    else { tail.next = l2; l2 = l2.next; }
    tail = tail.next;
  }

  tail.next = l1 ?? l2; // 剩下的整条接上，不用逐个搬
  return dummy.next;
}
```

`tail.next = l1 ?? l2` 是精髓：循环结束时最多剩一条非空链。

### 4.2 合并 K 个有序链表：分治

```ts
function mergeKLists(lists: Array<ListNode | null>): ListNode | null {
  if (lists.length === 0) return null;

  const divide = (l: number, r: number): ListNode | null => {
    if (l === r) return lists[l];
    const mid = (l + r) >> 1;
    const left = divide(l, mid);
    const right = divide(mid + 1, r);
    return mergeTwoLists(left, right); // 复用 4.1
  };

  return divide(0, lists.length - 1);
}
```

复杂度：每层合并总量 O(N)，共 log k 层 → **O(N log k)**（N 是节点总数）。逐条两两串行合并是 O(Nk)，差一个量级。

## 5. 快慢指针：找中点、判环、相交

### 5.1 回文链表：三模板合体

```ts
function isPalindrome(head: ListNode | null): boolean {
  // 1. 找中点：slow 停在前半段末尾
  let slow = head;
  let fast = head;
  while (fast?.next && fast.next.next) {
    slow = slow!.next;
    fast = fast.next.next;
  }

  // 2. 反转后半段
  let prev: ListNode | null = null;
  let cur = slow!.next;
  while (cur) {
    const next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
  }

  // 3. 逐段比对
  let p1 = head;
  let p2 = prev;
  while (p2) {
    if (p1!.val !== p2.val) return false;
    p1 = p1!.next;
    p2 = p2.next;
  }
  return true;
}
```

中点判断的两种写法要分清：

| 循环条件 | 偶数个节点时 slow 停在 | 适用 |
| --- | --- | --- |
| `while (fast?.next)` | 后半段的第一个 | 反转后半段（本解法） |
| `while (fast?.next && fast.next.next)` | 前半段的最后一个 | 切成两半、归并排序 |

面试如果要求"不能改原链表"，比对完再把后半段反转回去即可（多写一次 3.1）。

### 5.2 环形链表 II

```ts
function detectCycle(head: ListNode | null): ListNode | null {
  let slow = head;
  let fast = head;

  while (fast?.next) {
    slow = slow!.next;
    fast = fast.next.next;
    if (slow === fast) {
      let p = head;
      while (p !== slow) {
        p = p!.next;
        slow = slow!.next;
      }
      return p;
    }
  }
  return null;
}
```

数学依据：设头到入口 `a`、入口到相遇点 `b`、环长 `c`。相遇时快指针走了慢指针的两倍：`2(a+b) = a+b+kc`，化简得 `a = (k−1)c + (c−b)`。所以从头走 `a` 步、从相遇点走 `c−b` 步，会同时到达入口。

### 5.3 相交链表：走位消除长度差

```ts
function getIntersectionNode(
  headA: ListNode | null,
  headB: ListNode | null,
): ListNode | null {
  let p = headA;
  let q = headB;
  while (p !== q) {
    p = p ? p.next : headB; // 走完 A 接 B
    q = q ? q.next : headA; // 走完 B 接 A
  }
  return p;
}
```

两人走的总路程都是 `lenA + lenB`，所以若有交点必然同时到达；若无交点，最后会同时变成 `null`（退出循环）。**三行代码，不需要先算长度。**

## 6. 常见坑

| 现象 | 根因 | 解法 |
| --- | --- | --- |
| 删头节点后结果不对 | 返回了 `head` 而不是 `dummy.next` | 所有 dummy 题统一 `return dummy.next` |
| 删除倒数第 N 个，删错了位置 | `while (fast)` 导致 `slow` 停在目标本身 | `while (fast.next)` |
| 反转后链断了 | 没先存 `next` | "存、反、进、进" |
| 递归反转爆栈 | 链表过长 | 改迭代版 |
| 合并后尾部有环 | 复用了原链表节点又接错 | 合并只改 `next`，不要创建环 |
| 回文判断改坏了链表 | 反转后没恢复 | 需要保留原链时再反转回去 |
| 相交链表死循环 | 两条链无交点且写法有误 | 标准写法会自动落到 `p === q === null` |
| 越界崩溃 | `node.next.next` 前没判空 | 先判 `node?.next` |

---

## 7. 小结

- 三个模板：dummy（消灭头特判）、反转（存反进进）、快慢（中点/环/相交）。
- 反转两版都要会：迭代 O(1) 空间，递归 O(n) 栈空间。
- 合并：dummy + 尾插，`??` 接剩余；K 条用分治 O(N log k)。
- 回文链表 = 找中点 + 反转后半 + 比对；相交链表 = 走位消除长度差。
