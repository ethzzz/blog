写文章时总有几个语法记不住，索性整理一张速查表放这儿。

## 标题与强调

```markdown
# 一级标题
## 二级标题
### 三级标题

**加粗** 和 *斜体*，还有 `行内代码`。
```

效果：**加粗** 和 *斜体*，还有 `行内代码`。

## 列表

无序列表：

- 苹果
- 香蕉
  - 香蕉派
- 橙子

有序列表：

1. 写草稿
2. 校对一遍
3. 构建发布

## 引用

> 引用一段话，适合放金句或者注意事项。
>
> 可以有多段。

## 代码块

行内用反引号，整块用三个反引号并标注语言：

```js
function greet(name) {
	return `你好，${name}`;
}

console.log(greet('世界'));
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](/path/to/image.png)
```

## 表格

| 语法 | 用途 | 备注 |
| --- | --- | --- |
| `#` | 标题 | 一到六级 |
| `>` | 引用 | 可嵌套 |
| `-` | 无序列表 | 也可用 `*` |
| ` ``` ` | 代码块 | 标注语言可高亮 |

## 分割线

三个以上的减号：

---

## 转义

想显示星号本身而不是斜体，在前面加反斜杠：`\*不是斜体\*`。

写文章时忘了什么，回来看这篇就行。
