## 1. 最长递增子序列（LIS）

**300 题**：找最长的严格递增子序列长度（可不连续）。

### 1.1 O(n²) 定义式 DP

`dp[i]` = **以 `nums[i]` 结尾**的 LIS 长度：

```ts
function lengthOfLIS(nums: number[]): number {
  const n = nums.length;
  if (n === 0) return 0;

  const dp = new Array(n).fill(1); // 每个元素自己就是长度 1
  let ans = 1;

  for (let i = 1; i < n; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
    }
    ans = Math.max(ans, dp[i]);
  }
  return ans;
}
```

两个关键点：

- **状态必须锚定"以 i 结尾"**——只有这样，"前面的比它小"才构成合法转移；
- **答案不是 `dp[n-1]` 而是 `max(dp)`**——最长子序列可能以任何位置结尾。

如果状态写成"前 i 个元素里的 LIS 长度"，就无法判断新元素能不能接上，这是 LIS 最常见的错误状态定义。

### 1.2 O(n log n) 贪心 + 二分

维护 `tails`：`tails[k]` = 长度为 `k+1` 的递增子序列的**最小结尾**。

```ts
function lengthOfLISFast(nums: number[]): number {
  const tails: number[] = [];

  for (const x of nums) {
    // 找第一个 >= x 的位置（lower_bound）
    let l = 0;
    let r = tails.length;
    while (l < r) {
      const mid = (l + r) >> 1;
      if (tails[mid] < x) l = mid + 1;
      else r = mid;
    }

    if (l === tails.length) tails.push(x); // 比所有结尾都大 → LIS 变长
    else tails[l] = x;                     // 替换成更小的结尾
  }
  return tails.length;
}
```

直觉：`tails[l] = x` 是"在同样长度下把结尾换得更小，给未来留更多机会"。

> **`tails` 不是 LIS 本身，长度才是答案。** 这句话是面试官验证你是否真懂的标准问题。要还原具体序列，需要额外记录每个元素的前驱下标，另建 `pre` 数组回溯。

## 2. LCS：二维 DP 的样板

**1143 题**：两个字符串的最长公共子序列长度。编辑距离、不相交的线、删除操作，全是它的变装。

**三步走**：

1. `dp[i][j]` = `s1` 前 i 个字符与 `s2` 前 j 个字符的 LCS 长度；
2. 末尾相同 → `dp[i-1][j-1] + 1`；不同 → `max(dp[i-1][j], dp[i][j-1])`；
3. `dp[0][*] = dp[*][0] = 0`（空串），双重循环正序。

```ts
function longestCommonSubsequence(s1: string, s2: string): number {
  const m = s1.length;
  const n = s2.length;
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      dp[i][j] = s1[i - 1] === s2[j - 1]
        ? dp[i - 1][j - 1] + 1
        : Math.max(dp[i - 1][j], dp[i][j - 1]);
    }
  }
  return dp[m][n];
}
```

**两个 off-by-one 是本篇最容易错的地方**：

| 位置 | 规则 | 记法 |
| --- | --- | --- |
| `dp` 尺寸 | `(m+1) × (n+1)` | 多一行一列表示"空串" |
| 字符串下标 | `s1[i-1]`、`s2[j-1]` | dp 的第 i 格对应字符串第 i-1 个 |

### 2.1 空间压缩到 O(n)

`dp[i][*]` 只依赖 `dp[i-1][*]` 和当前行左侧，所以两行滚动即可：

```ts
function lcsRolling(s1: string, s2: string): number {
  const n = s2.length;
  let prev = new Array(n + 1).fill(0);
  let cur = new Array(n + 1).fill(0);

  for (let i = 1; i <= s1.length; i++) {
    for (let j = 1; j <= n; j++) {
      cur[j] = s1[i - 1] === s2[j - 1]
        ? prev[j - 1] + 1
        : Math.max(prev[j], cur[j - 1]); // 注意：cur[j-1] 是当前行左侧
    }
    [prev, cur] = [cur, prev]; // 交换，cur 变成下一轮的草稿区
  }
  return prev[n];
}
```

压缩后要特别小心两个引用：`prev[j]` 是**上一行**，`cur[j-1]` 是**当前行左侧**，写反了结果就错，但小样例可能仍然通过。

## 3. 编辑距离

**72 题**：把 `w1` 变成 `w2` 的最少操作次数（插入/删除/替换）。

**三步走**：

1. `dp[i][j]` = `w1` 前 i 个字符变成 `w2` 前 j 个字符的最少操作数；
2. 末尾相同 → `dp[i-1][j-1]`；不同 → `1 + min(替换 dp[i-1][j-1], 删 dp[i-1][j], 插 dp[i][j-1])`；
3. `dp[i][0] = i`（删光），`dp[0][j] = j`（逐个插入）。

```ts
function minDistance(w1: string, w2: string): number {
  const m = w1.length;
  const n = w2.length;
  const dp = Array.from({ length: m + 1 }, () => new Array(n + 1).fill(0));

  for (let i = 0; i <= m; i++) dp[i][0] = i;
  for (let j = 0; j <= n; j++) dp[0][j] = j;

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      if (w1[i - 1] === w2[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1];
      } else {
        dp[i][j] = 1 + Math.min(
          dp[i - 1][j - 1], // 替换
          dp[i - 1][j],     // 删掉 w1 末尾
          dp[i][j - 1],     // 在 w1 插入（等价于删 w2 末尾）
        );
      }
    }
  }
  return dp[m][n];
}
```

**三种操作对应哪个格子**，要能指着表格说清楚：

```text
        w2[0..j-1]
      ┌────┬────┬────┐
w1[i-1]│ ↖  │ ←  │ ...│   ↖ 替换（dp[i-1][j-1]）
      │ ↑  │ ?  │    │   ↑ 删除（dp[i-1][j]）
      └────┴────┴────┘   ← 插入（dp[i][j-1]）
```

面试时先画 5×5 表格演示两行填法，再写代码——**编辑距离考的是"能不能讲清转移的物理含义"**，代码只是结果。

### 3.1 一维压缩：必须多存一个对角值

```ts
function minDistance1D(w1: string, w2: string): number {
  const n = w2.length;
  let dp = Array.from({ length: n + 1 }, (_, j) => j); // 第 0 行

  for (let i = 1; i <= w1.length; i++) {
    let diag = dp[0]; // 上一行的 dp[j-1]，先存起来
    dp[0] = i;

    for (let j = 1; j <= n; j++) {
      const up = dp[j];       // 覆盖前先存"上一行同列"
      dp[j] = w1[i - 1] === w2[j - 1]
        ? diag
        : 1 + Math.min(diag, dp[j], dp[j - 1]);
      diag = up;              // 给下一列当对角值
    }
  }
  return dp[n];
}
```

压缩的关键就是那个 `diag`：二维版的 `dp[i-1][j-1]` 在一维里已经被覆盖了，必须提前保存。

## 4. 区间 DP：从小洞合并到大洞

**516 题 最长回文子序列**：

1. `dp[i][j]` = `s[i..j]` 内最长回文子序列长度；
2. `s[i] === s[j]` → `dp[i+1][j-1] + 2`；否则 `max(dp[i+1][j], dp[i][j-1])`；
3. `dp[i][i] = 1`。

遍历顺序有两种写法，等价的：

```ts
// 写法 A：i 倒序（依赖 i+1 和 j-1，保证先算短的）
function longestPalindromeSubseqA(s: string): number {
  const n = s.length;
  const dp = Array.from({ length: n }, () => new Array(n).fill(0));

  for (let i = n - 1; i >= 0; i--) {
    dp[i][i] = 1;
    for (let j = i + 1; j < n; j++) {
      dp[i][j] = s[i] === s[j]
        ? dp[i + 1][j - 1] + 2
        : Math.max(dp[i + 1][j], dp[i][j - 1]);
    }
  }
  return n ? dp[0][n - 1] : 0;
}

// 写法 B：枚举区间长度（更通用，复杂区间 DP 都用这个骨架）
function longestPalindromeSubseqB(s: string): number {
  const n = s.length;
  if (n === 0) return 0;
  const dp = Array.from({ length: n }, () => new Array(n).fill(0));
  for (let i = 0; i < n; i++) dp[i][i] = 1;

  for (let len = 2; len <= n; len++) {       // 先枚举长度
    for (let i = 0; i + len - 1 < n; i++) {  // 再枚举起点
      const j = i + len - 1;
      dp[i][j] = s[i] === s[j]
        ? dp[i + 1][j - 1] + 2
        : Math.max(dp[i + 1][j], dp[i][j - 1]);
    }
  }
  return dp[0][n - 1];
}
```

**区间 DP 的通用口诀**：`dp[i][j]` 依赖谁，就保证谁先算。写法 B 的"长度 → 起点 → 分割点"是最稳的骨架：

```text
for (len = 2..n)
  for (i = 0; i + len - 1 < n)
    j = i + len - 1
    for (k = i..j-1)  // 需要枚举分割点的题才加这层
      dp[i][j] = ...
```

分不清顺序时**画依赖箭头**，比背口诀可靠。

## 5. 常见坑

| 现象 | 根因 | 解法 |
| --- | --- | --- |
| LIS 答案偏小 | 返回 `dp[n-1]` | 返回 `max(dp)` |
| LIS 状态写错 | 定义成"前 i 个的 LIS" | 必须"以 i 结尾" |
| `tails` 当成答案 | 误以为它是子序列 | 只有长度是答案 |
| LCS 结果差一 | `dp` 尺寸没 +1 / 下标没 -1 | 表 +1、串 -1 |
| 压缩后结果错但样例过 | `prev[j]` 与 `cur[j-1]` 写反 | 记住"上一行 vs 当前行左侧" |
| 编辑距离压缩错 | 没保存对角值 | 用 `diag` 暂存 |
| 区间 DP 用了错值 | 先算了长区间 | 长度从 2 递增，或 i 倒序 |
| 空串崩溃 | 没处理 `n === 0` | 提前返回 |

---

## 6. 小结

- LIS：状态"以 i 结尾"，答案 `max(dp)`；O(n log n) 用 `tails`，长度才是答案。
- LCS：`(m+1)×(n+1)` 表，下标 -1；可压成两行。
- 编辑距离：三种操作对应三个格子；一维压缩要存 `diag`。
- 区间 DP：按长度递增（或 i 倒序）保证短区间先算。
