## 环境准备

安装 JDK 21（推荐 Temurin、Corretto 或 Oracle OpenJDK），然后检查：

```bash
java -version
javac -version
```

创建 `Hello.java`：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java " + Runtime.version());
    }
}
```

直接运行（Java 11 及以上支持单文件运行）：

```bash
java Hello.java
```

也可以先编译再运行：

```bash
javac Hello.java
java Hello
```

**推荐工具：** IntelliJ IDEA（Community 版免费）或 VS Code 加 Java 扩展包。

**核心思想：** Java 源码先编译成字节码，再由 JVM（Java 虚拟机）运行。同一份字节码可以在任何装有 JVM 的系统上运行。

## 1. 语言基础

**概念：** Java 是静态类型语言，每个变量都有明确的类型，编译器会在运行前帮你发现许多错误。

### 变量与类型

```java
int age = 30;                 // 32 位整数
long big = 10_000_000_000L;   // 64 位整数，下划线增强可读性
double price = 19.99;         // 64 位浮点数
boolean active = true;
char letter = 'A';

var name = "Ada";             // 类型推断，仍然是 String
final int MAX = 100;          // final：不可再赋值
```

| 类型 | 大小 | 用途 |
| --- | --- | --- |
| `int` | 32 位 | 一般整数 |
| `long` | 64 位 | 大整数、时间戳 |
| `double` | 64 位 | 小数（不要用于金额） |
| `boolean` | - | 真或假 |
| `BigDecimal` | 任意精度 | 金额和精确小数 |

**金额永远不要用 `double`。** 用 `BigDecimal` 或以“分”为单位的 `long`。

### 字符串

```java
String s = "Hello, Java";
System.out.println(s.length());           // 11
System.out.println(s.toUpperCase());      // HELLO, JAVA
System.out.println(s.substring(7));       // Java
System.out.println(s.contains("Java"));   // true
System.out.println(String.join("-", "a", "b", "c")); // a-b-c

String msg = String.format("%s is %d years old", name, age);

// 文本块：多行字符串
String json = """
    {
      "name": "Ada",
      "age": 30
    }
    """;
```

**重要：** 比较字符串内容要用 `equals`，不能用 `==`（`==` 比较的是对象引用）。

```java
String a = new String("hi");
String b = new String("hi");
System.out.println(a == b);       // false
System.out.println(a.equals(b));  // true
```

字符串不可变。大量拼接时使用 `StringBuilder`：

```java
var sb = new StringBuilder();
for (int i = 0; i < 5; i++) sb.append(i).append(',');
System.out.println(sb);  // 0,1,2,3,4,
```

### 控制流

```java
int score = 85;
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C");
}

// switch 表达式（现代写法，有返回值，不会“穿透”）
int day = 3;
String type = switch (day) {
    case 1, 7 -> "周末";
    case 2, 3, 4, 5, 6 -> "工作日";
    default -> throw new IllegalArgumentException("无效的日期: " + day);
};

// 循环
for (int i = 0; i < 3; i++) System.out.println(i);

int[] numbers = {5, 3, 8};
for (int n : numbers) System.out.println(n);   // 增强 for 循环

int count = 0;
while (count < 3) count++;
```

### 方法

```java
public class MathUtil {
    public static int add(int a, int b) {
        return a + b;
    }

    // 方法重载：同名，参数不同
    public static double add(double a, double b) {
        return a + b;
    }

    // 可变参数
    public static int sum(int... values) {
        int total = 0;
        for (int v : values) total += v;
        return total;
    }

    public static void main(String[] args) {
        System.out.println(add(2, 3));      // 5
        System.out.println(sum(1, 2, 3, 4)); // 10
    }
}
```

## 2. 面向对象编程（OOP）

**概念：** 把数据和操作数据的行为放在一起。四大支柱：封装、继承、多态、抽象。

### 封装

```java
public class BankAccount {
    private final String id;
    private long balanceCents;   // 私有：外部不能直接修改

    public BankAccount(String id, long initialCents) {
        if (initialCents < 0) throw new IllegalArgumentException("初始余额不能为负");
        this.id = id;
        this.balanceCents = initialCents;
    }

    public void deposit(long cents) {
        if (cents <= 0) throw new IllegalArgumentException("金额必须为正");
        balanceCents += cents;
    }

    public void withdraw(long cents) {
        if (cents > balanceCents) throw new IllegalStateException("余额不足");
        balanceCents -= cents;
    }

    public long getBalanceCents() { return balanceCents; }
    public String getId() { return id; }
}
```

通过方法而不是公开字段访问数据，这样类就能保证自己的规则始终成立。

### 继承、抽象类与多态

```java
abstract class Animal {
    protected final String name;
    Animal(String name) { this.name = name; }

    abstract String sound();          // 子类必须实现

    void speak() {
        System.out.println(name + " says " + sound());
    }
}

class Dog extends Animal {
    Dog(String name) { super(name); }
    @Override String sound() { return "Woof"; }
}

class Cat extends Animal {
    Cat(String name) { super(name); }
    @Override String sound() { return "Meow"; }
}

public class Zoo {
    public static void main(String[] args) {
        Animal[] animals = { new Dog("Rex"), new Cat("Tom") };
        for (Animal a : animals) a.speak();   // 多态：运行时决定调用哪个实现
    }
}
```

### 接口

接口定义“能做什么”，类通过 `implements` 实现。一个类可以实现多个接口，但只能继承一个类。

```java
interface PaymentMethod {
    boolean pay(long cents);

    default String describe() {          // 默认方法
        return "支付方式: " + getClass().getSimpleName();
    }
}

class CreditCard implements PaymentMethod {
    public boolean pay(long cents) {
        System.out.println("信用卡支付 " + cents);
        return true;
    }
}
```

**设计原则：** 优先使用组合而不是继承，面向接口编程而不是面向具体实现。

### Record、枚举与密封类型

```java
// record：不可变数据类，自动生成构造器、getter、equals、hashCode、toString
record Point(int x, int y) {
    Point {   // 紧凑构造器：验证
        if (x < 0 || y < 0) throw new IllegalArgumentException("坐标不能为负");
    }
    double distanceTo(Point other) {
        return Math.hypot(x - other.x, y - other.y);
    }
}

// 枚举
enum OrderStatus {
    NEW("新建"), PAID("已支付"), SHIPPED("已发货");

    private final String label;
    OrderStatus(String label) { this.label = label; }
    public String label() { return label; }
}

// 密封接口 + 模式匹配 switch：编译器会检查是否覆盖了所有情况
sealed interface Shape permits Circle, Rectangle {}
record Circle(double radius) implements Shape {}
record Rectangle(double width, double height) implements Shape {}

class Geometry {
    static double area(Shape shape) {
        return switch (shape) {
            case Circle c -> Math.PI * c.radius() * c.radius();
            case Rectangle r -> r.width() * r.height();
        };
    }
}
```

### equals 与 hashCode

如果你重写了 `equals`，就必须同时重写 `hashCode`，否则对象放进 `HashMap` 或 `HashSet` 时会出错。最简单的做法是使用 `record`，它们会自动生成。

## 3. 集合与泛型

**概念：** 集合框架提供现成的数据结构。泛型让它们在编译期就保证类型安全。

| 接口 | 常用实现 | 特点 |
| --- | --- | --- |
| `List` | `ArrayList` | 有序，可重复，按索引访问快 |
| `Set` | `HashSet`、`TreeSet` | 不重复；`TreeSet` 有序 |
| `Map` | `HashMap`、`TreeMap` | 键值对；`TreeMap` 按键排序 |
| `Deque` | `ArrayDeque` | 栈和队列 |

```java
import java.util.*;

List<String> names = new ArrayList<>();
names.add("Ada");
names.add("Linus");
names.add("Grace");
Collections.sort(names);
System.out.println(names);   // [Ada, Grace, Linus]

Set<Integer> unique = new HashSet<>(List.of(1, 2, 2, 3, 3));
System.out.println(unique.size());   // 3

Map<String, Integer> stock = new HashMap<>();
stock.put("apple", 10);
stock.put("pear", 4);
stock.merge("apple", 5, Integer::sum);          // apple -> 15
stock.computeIfAbsent("kiwi", k -> 0);          // 不存在才放入
for (var entry : stock.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}

// 不可变集合
List<String> fixed = List.of("a", "b");
// fixed.add("c");  // 抛出 UnsupportedOperationException
```

### 排序

```java
record Person(String name, int age) {}

var people = new ArrayList<>(List.of(
    new Person("Ada", 36), new Person("Bob", 25), new Person("Cy", 36)));

people.sort(Comparator.comparingInt(Person::age).reversed()
                      .thenComparing(Person::name));
System.out.println(people);
```

### 泛型

```java
// 泛型类
class Box<T> {
    private final T value;
    Box(T value) { this.value = value; }
    T get() { return value; }
}

// 泛型方法 + 有界类型：T 必须可比较
static <T extends Comparable<T>> T max(List<T> items) {
    T best = items.get(0);
    for (T item : items) {
        if (item.compareTo(best) > 0) best = item;
    }
    return best;
}

System.out.println(max(List.of(3, 9, 4)));        // 9
System.out.println(max(List.of("a", "z", "m")));   // z
```

**性能提示：** 默认使用 `ArrayList` 和 `HashMap`。只有在确实需要有序遍历、并发访问等特性时才换成别的实现。

## 4. Lambda、Stream 与 Optional

**概念：** Lambda 是可以当作值传递的简短函数。Stream 用声明式的方式处理集合：说明“要什么”，而不是“怎么循环”。

### Lambda 与函数式接口

```java
import java.util.function.*;

Function<Integer, Integer> square = x -> x * x;
Predicate<String> isLong = s -> s.length() > 5;
Supplier<String> greeting = () -> "Hello";
BiFunction<Integer, Integer, Integer> add = (a, b) -> a + b;
Consumer<String> printer = System.out::println;   // 方法引用

System.out.println(square.apply(5));        // 25
System.out.println(isLong.test("Java"));    // false
printer.accept(greeting.get());
```

### Stream

```java
import java.util.stream.*;

record Order(String customer, String category, double amount) {}

var orders = List.of(
    new Order("Ada", "book", 30),
    new Order("Bob", "book", 20),
    new Order("Ada", "toy", 50),
    new Order("Cy", "toy", 15));

// 过滤 + 转换 + 收集
List<String> bigCustomers = orders.stream()
    .filter(o -> o.amount() >= 30)
    .map(Order::customer)
    .distinct()
    .sorted()
    .toList();

// 汇总
double total = orders.stream().mapToDouble(Order::amount).sum();

// 分组
Map<String, Double> totalByCategory = orders.stream()
    .collect(Collectors.groupingBy(Order::category,
             Collectors.summingDouble(Order::amount)));

System.out.println(bigCustomers);      // [Ada]
System.out.println(total);             // 115.0
System.out.println(totalByCategory);   // {book=50.0, toy=65.0}

// 其他常用操作
boolean anyBig = orders.stream().anyMatch(o -> o.amount() > 40);
Optional<Order> max = orders.stream().max(Comparator.comparingDouble(Order::amount));
String names = orders.stream().map(Order::customer).collect(Collectors.joining(", "));
```

**注意：** Stream 只能消费一次。不要在 `map` 或 `filter` 里写有副作用的代码。简单循环更清晰时，就用循环。

### Optional

`Optional` 表示“可能没有值”，用来取代到处返回 `null`。

```java
static Optional<String> findEmail(String user) {
    return user.equals("ada") ? Optional.of("ada@example.com") : Optional.empty();
}

String email = findEmail("bob").orElse("unknown@example.com");

findEmail("ada").ifPresent(e -> System.out.println("发送邮件到 " + e));

String domain = findEmail("ada")
    .map(e -> e.substring(e.indexOf('@') + 1))
    .orElseThrow(() -> new IllegalStateException("没有邮箱"));
```

**规则：** `Optional` 适合做方法的返回值，不要用作字段或方法参数。

## 5. 异常处理

**概念：** 异常把“正常流程”和“出错处理”分开。Java 区分两类异常：

| 类型 | 例子 | 是否强制处理 |
| --- | --- | --- |
| 受检异常（checked） | `IOException`、`SQLException` | 是，必须 `try/catch` 或 `throws` |
| 非受检异常（unchecked） | `IllegalArgumentException`、`NullPointerException` | 否，通常表示编程错误 |

```java
import java.nio.file.*;
import java.io.IOException;

// try-with-resources：自动关闭资源，即使出错也会关闭
static String readFirstLine(Path path) {
    try (var lines = Files.lines(path)) {
        return lines.findFirst().orElse("");
    } catch (NoSuchFileException e) {
        return "文件不存在";
    } catch (IOException e) {
        throw new UncheckedIOException(e);   // 包装并向上抛出
    }
}
```

### 自定义异常

```java
public class InsufficientFundsException extends RuntimeException {
    private final long shortfallCents;

    public InsufficientFundsException(long shortfallCents) {
        super("余额不足，还差 " + shortfallCents + " 分");
        this.shortfallCents = shortfallCents;
    }

    public long getShortfallCents() { return shortfallCents; }
}
```

### 良好实践

- 抛出具体的异常类型，并写清楚信息，不要抛 `Exception` 或 `RuntimeException` 本身。
- 不要吞掉异常：`catch (Exception e) {}` 会掩盖问题。至少要记录日志。
- 包装异常时保留原始原因：`new MyException("信息", cause)`。
- 用异常处理“异常情况”，不要用它控制正常流程。
- 多个异常处理方式相同时，使用多重捕获：`catch (IOException | ParseException e)`。

## 6. 文件与 I/O

**概念：** `java.nio.file` 包（NIO.2）是现代的文件操作方式。用 `Path` 表示路径，用 `Files` 完成读写。

```java
import java.io.IOException;
import java.nio.file.*;
import java.util.stream.Stream;

public class FileDemo {
    public static void main(String[] args) throws IOException {
        Path dir = Path.of("data");
        Path file = dir.resolve("notes.txt");

        Files.createDirectories(dir);
        Files.writeString(file, "第一行\n");
        Files.writeString(file, "第二行\n", StandardOpenOption.APPEND);

        String text = Files.readString(file);
        System.out.println(text);

        // 大文件：逐行读取，不要一次性读入内存
        try (Stream<String> lines = Files.lines(file)) {
            long count = lines.filter(l -> !l.isBlank()).count();
            System.out.println("非空行数: " + count);
        }

        // 遍历目录
        try (Stream<Path> entries = Files.list(dir)) {
            entries.forEach(p -> System.out.println(p.getFileName()));
        }

        System.out.println(Files.exists(file));   // true
        Files.deleteIfExists(file);
    }
}
```

**要点：**

- `Files.lines` 和 `Files.list` 返回的 Stream 持有文件句柄，必须放在 `try-with-resources` 中。
- 读写文本时明确指定字符集更稳妥：`Files.readString(file, StandardCharsets.UTF_8)`。
- 处理用户提供的文件名时，要防止路径遍历：用 `normalize()` 后检查结果是否仍在允许的目录内。

## 7. 并发编程

**概念：** 并发让程序同时处理多件事。Java 提供了线程、线程池、`CompletableFuture`，以及 Java 21 的虚拟线程。

### 线程池

不要手动创建大量线程，使用线程池：

```java
import java.util.concurrent.*;

ExecutorService pool = Executors.newFixedThreadPool(4);

Future<Integer> future = pool.submit(() -> {
    Thread.sleep(500);        // 模拟耗时操作
    return 42;
});

System.out.println("做其他事情...");
System.out.println("结果: " + future.get());   // 阻塞直到完成

pool.shutdown();   // 不再接受新任务；一定要关闭
```

### CompletableFuture：组合异步任务

```java
CompletableFuture<String> user = CompletableFuture.supplyAsync(() -> "ada");
CompletableFuture<Integer> orderCount = CompletableFuture.supplyAsync(() -> 3);

user.thenCombine(orderCount, (u, n) -> u + " 有 " + n + " 个订单")
    .exceptionally(ex -> "加载失败: " + ex.getMessage())
    .thenAccept(System.out::println)
    .join();
```

### 虚拟线程（Java 21）

虚拟线程非常轻量，可以同时创建几十万个。它特别适合大量阻塞 I/O 的场景（HTTP 调用、数据库访问），而且可以继续使用简单直白的阻塞式代码。

```java
import java.time.Duration;
import java.util.stream.IntStream;

try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    IntStream.range(0, 10_000).forEach(i ->
        executor.submit(() -> {
            Thread.sleep(Duration.ofSeconds(1));
            return i;
        }));
}   // 退出 try 时会等待所有任务完成
```

**注意：** 虚拟线程适合 I/O 密集型任务。CPU 密集型任务仍然受限于 CPU 核数，不要因此创建更多线程。

### 线程安全

多个线程同时修改同一份数据会产生竞态条件：

```java
class Counter {
    private int unsafe = 0;
    private final java.util.concurrent.atomic.AtomicInteger safe =
        new java.util.concurrent.atomic.AtomicInteger();

    void incrementUnsafe() { unsafe++; }                 // 错误：不是原子操作
    synchronized void incrementSync() { unsafe++; }      // 正确：加锁
    void incrementAtomic() { safe.incrementAndGet(); }   // 正确：原子类，通常更快
}
```

| 工具 | 用途 |
| --- | --- |
| `synchronized` | 简单的互斥锁 |
| `AtomicInteger`、`AtomicLong` | 无锁的计数器 |
| `ConcurrentHashMap` | 线程安全的 Map |
| `ReentrantLock` | 需要超时、可中断等高级功能时 |
| `CountDownLatch`、`Semaphore` | 协调多个线程 |

**经验法则：** 优先使用不可变对象和 `java.util.concurrent` 里的现成工具，尽量少写 `synchronized`。

## 8. Maven 与单元测试

**概念：** Maven（或 Gradle）负责管理依赖、编译、测试和打包。

### 标准项目结构

```
my-app/
  pom.xml
  src/
    main/
      java/com/example/app/    源代码
      resources/               配置文件
    test/
      java/com/example/app/    测试代码
```

最小的 `pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0">
  <modelVersion>4.0.0</modelVersion>

  <groupId>com.example</groupId>
  <artifactId>my-app</artifactId>
  <version>1.0.0</version>

  <properties>
    <maven.compiler.release>21</maven.compiler.release>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  </properties>

  <dependencies>
    <dependency>
      <groupId>org.junit.jupiter</groupId>
      <artifactId>junit-jupiter</artifactId>
      <version>5.11.0</version>
      <scope>test</scope>
    </dependency>
  </dependencies>
</project>
```

常用命令：

```bash
mvn compile          # 编译
mvn test             # 运行测试
mvn package          # 打成 jar
mvn clean verify     # 清理后完整构建
```

### 用 JUnit 5 写测试

```java
// src/main/java/com/example/app/PriceCalculator.java
package com.example.app;
```

```java
import org.springframework.http.*;
import org.springframework.web.bind.annotation.*;
import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicLong;

@RestController
@RequestMapping("/api/todos")
public class TodoController {

    record Todo(Long id, String title, boolean done) {}
    record CreateTodo(String title) {}

    private final Map<Long, Todo> store = new ConcurrentHashMap<>();
    private final AtomicLong ids = new AtomicLong();

    @GetMapping
    public List<Todo> list() {
        return List.copyOf(store.values());
    }

    @GetMapping("/{id}")
    public ResponseEntity<Todo> get(@PathVariable Long id) {
        Todo todo = store.get(id);
        return todo == null ? ResponseEntity.notFound().build() : ResponseEntity.ok(todo);
    }

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public Todo create(@RequestBody CreateTodo body) {
        long id = ids.incrementAndGet();
        Todo todo = new Todo(id, body.title(), false);
        store.put(id, todo);
        return todo;
    }

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void delete(@PathVariable Long id) {
        store.remove(id);
    }
}
```

```java
import org.springframework.http.*;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.*;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(NotFoundException.class)
    public ProblemDetail handleNotFound(NotFoundException ex) {
        return ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, ex.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ProblemDetail handleValidation(MethodArgumentNotValidException ex) {
        var problem = ProblemDetail.forStatusAndDetail(
            HttpStatus.BAD_REQUEST, "请求参数无效");
        var errors = new java.util.HashMap<String, String>();
        ex.getBindingResult().getFieldErrors()
            .forEach(e -> errors.put(e.getField(), e.getDefaultMessage()));
        problem.setProperty("errors", errors);
        return problem;
    }

    @ExceptionHandler(Exception.class)
    public ProblemDetail handleUnexpected(Exception ex) {
        // 记录日志，但不向客户端暴露内部细节
        return ProblemDetail.forStatusAndDetail(
            HttpStatus.INTERNAL_SERVER_ERROR, "服务器内部错误");
    }
}
```

`ProblemDetail` 遵循 RFC 9457（Problem Details）标准，Spring 6 开始内置支持，输出的 JSON 格式统一，前端处理起来很方便。

## 12. 数据库：Spring Data JPA

**概念：** JPA 是 Java 的 ORM 标准：你操作对象，框架负责生成 SQL。Spring Data JPA 在此基础上，让你只写接口就能获得常用的增删改查。

### 配置

`application.yml`：

### Service、事务与 DTO

```java
public record PostResponse(Long id, String title, String body, String authorEmail, Instant createdAt) {
    static PostResponse from(Post p) {
        return new PostResponse(p.getId(), p.getTitle(), p.getBody(),
                                p.getAuthor().getEmail(), p.getCreatedAt());
    }
}

@Service
public class PostService {
    private final PostRepository posts;
    private final UserRepository users;

    public PostService(PostRepository posts, UserRepository users) {
        this.posts = posts;
        this.users = users;
    }

    @Transactional(readOnly = true)
    public Page<PostResponse> list(int page, int size) {
        var pageable = PageRequest.of(page, Math.min(size, 100),
                                      Sort.by("createdAt").descending());
        return posts.findAll(pageable).map(PostResponse::from);
    }

    @Transactional
    public PostResponse create(Long authorId, String title, String body) {
        User author = users.getReferenceById(authorId);
        Post saved = posts.save(new Post(author, title, body));
        return PostResponse.from(saved);
    }

    @Transactional
    public PostResponse update(Long postId, Long userId, String title, String body) {
        Post post = posts.findWithAuthor(postId)
            .orElseThrow(() -> new NotFoundException("文章不存在"));
        if (!post.getAuthor().getId().equals(userId)) {
            throw new ForbiddenException("只能修改自己的文章");
        }
        post.update(title, body);   // 事务结束时，Hibernate 自动把变更写入数据库
        return PostResponse.from(post);
    }
}
```

**JPA 常见陷阱**

- **N+1 查询：** 遍历列表时逐个访问懒加载关联，会产生大量小查询。用 `join fetch` 或 `@EntityGraph`。
- **`LazyInitializationException`：** 在事务之外访问懒加载字段。解决办法是在 Service 的事务内完成转换，只把 DTO 返回给 Controller。
- **不要把实体直接返回给前端：** 会暴露内部字段（例如密码哈希），还可能触发懒加载。
- **`@Transactional` 只对通过 Spring 代理发起的调用生效：** 同一个类里的方法互相调用不会开启事务。
- 打开 `spring.jpa.show-sql=true`（仅开发时）检查实际生成的 SQL。

## 13. 认证与授权（Spring Security）

**概念：** 认证证明“你是谁”，授权决定“你能做什么”。Spring Security 通过过滤器链在请求到达 Controller 之前完成这两件事。下面实现无状态的 JWT 认证。

依赖：`spring-boot-starter-security` 和 `spring-boot-starter-oauth2-resource-server`。

### 安全配置

```java
import org.springframework.context.annotation.*;
import org.springframework.http.HttpMethod;
import org.springframework.security.config.Customizer;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.oauth2.server.resource.authentication.*;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableMethodSecurity
public class SecurityConfig {

    @Bean
    SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())    // 无状态 API，不使用 Cookie 会话
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**", "/actuator/health").permitAll()
                .requestMatchers(HttpMethod.GET, "/api/posts/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated())
            .oauth2ResourceServer(oauth -> oauth
                .jwt(jwt -> jwt.jwtAuthenticationConverter(jwtAuthConverter())));
        return http.build();
    }

    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();     // 永远不要明文存储密码
    }

    // 把 JWT 里的 roles 声明转换成 ROLE_xxx 权限
    private JwtAuthenticationConverter jwtAuthConverter() {
        var authorities = new JwtGrantedAuthoritiesConverter();
        authorities.setAuthoritiesClaimName("roles");
        authorities.setAuthorityPrefix("ROLE_");
        var converter = new JwtAuthenticationConverter();
        converter.setJwtGrantedAuthoritiesConverter(authorities);
        return converter;
    }
}
```

```java
@Service
public class TokenService {
    private final JwtEncoder encoder;

    public TokenService(JwtEncoder encoder) { this.encoder = encoder; }

    public String issue(User user) {
        Instant now = Instant.now();
        var claims = JwtClaimsSet.builder()
            .subject(String.valueOf(user.getId()))
            .issuedAt(now)
            .expiresAt(now.plus(Duration.ofMinutes(15)))   // 访问令牌要短命
            .claim("roles", List.of(user.getRole()))
            .build();
        var header = JwsHeader.with(MacAlgorithm.HS256).build();
        return encoder.encode(JwtEncoderParameters.from(header, claims)).getTokenValue();
    }
}
```

### 注册与登录接口

```java
public record RegisterRequest(@Email @NotBlank String email, @Size(min = 8) String password) {}
public record LoginRequest(@NotBlank String email, @NotBlank String password) {}

@RestController
@RequestMapping("/api/auth")
public class AuthController {
    private final UserRepository users;
    private final PasswordEncoder encoder;
    private final TokenService tokens;

    public AuthController(UserRepository users, PasswordEncoder encoder, TokenService tokens) {
        this.users = users;
        this.encoder = encoder;
        this.tokens = tokens;
    }

    @PostMapping("/register")
    @ResponseStatus(HttpStatus.CREATED)
    public void register(@Valid @RequestBody RegisterRequest req) {
        if (users.existsByEmail(req.email())) {
            throw new ConflictException("邮箱已被注册");
        }
        users.save(new User(req.email(), encoder.encode(req.password())));
    }

    @PostMapping("/login")
    public Map<String, String> login(@Valid @RequestBody LoginRequest req) {
        User user = users.findByEmail(req.email()).orElse(null);
        // “邮箱不存在”和“密码错误”使用相同的提示，避免泄露哪些邮箱已注册
        if (user == null || !encoder.matches(req.password(), user.getPasswordHash())) {
            throw new UnauthorizedException("邮箱或密码错误");
        }
        return Map.of("token", tokens.issue(user));
    }
}
```

```java
        when(service.get(99L)).thenThrow(new NotFoundException("Todo 99 不存在"));

        mvc.perform(get("/api/todos/99"))
           .andExpect(status().isNotFound());
    }

    @Test
    void rejectsBlankTitle() throws Exception {
        mvc.perform(post("/api/todos")
               .contentType(MediaType.APPLICATION_JSON)
               .content("{\"title\":\"\",\"priority\":1}"))
           .andExpect(status().isBadRequest());
    }
}
```

### 用 Testcontainers 做集成测试

Testcontainers 在测试时启动一个真实的 PostgreSQL 容器，比用内存数据库更接近生产环境。

```java
import org.springframework.boot.testcontainers.service.connection.ServiceConnection;
import org.testcontainers.containers.PostgreSQLContainer;
import org.testcontainers.junit.jupiter.*;

@SpringBootTest
@Testcontainers
class PostRepositoryIT {

    @Container
    @ServiceConnection              // 自动把容器的连接信息配置给 Spring
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:16");

    @Autowired UserRepository users;
    @Autowired PostRepository posts;

    @Test
    void savesAndFindsPostsByAuthor() {
        User author = users.save(new User("ada@example.com", "hash"));
        posts.save(new Post(author, "Hello", "World"));

        var found = posts.findByAuthorIdOrderByCreatedAtDesc(author.getId());

        assertEquals(1, found.size());
        assertEquals("Hello", found.get(0).getTitle());
    }
}
```

需要本机安装并运行 Docker。依赖：`spring-boot-testcontainers`、`org.testcontainers:junit-jupiter`、`org.testcontainers:postgresql`（测试范围）。

### Profile：不同环境用不同配置

```yaml
# application-dev.yml（本地开发）
```

### 日志

使用 SLF4J，Spring Boot 默认接入 Logback：

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

@Service
public class OrderService {
    private static final Logger log = LoggerFactory.getLogger(OrderService.class);

    public void place(long orderId) {
        log.info("下单开始 orderId={}", orderId);        // 用占位符，不要拼接字符串
        try {
            // ...
        } catch (Exception e) {
            log.error("下单失败 orderId={}", orderId, e);   // 最后一个参数传异常，会输出堆栈
            throw e;
        }
    }
}
```

**日志规则：** 使用正确的级别（ERROR、WARN、INFO、DEBUG）；绝不记录密码、令牌或完整的银行卡号；生产环境使用结构化（JSON）日志，并给每个请求附加追踪 ID。

### Actuator：健康检查与指标

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics,prometheus

    health:
      probes:
```

`/actuator/health` 用于负载均衡器和容器探针。`/actuator/prometheus`（需要 `micrometer-registry-prometheus` 依赖）供 Prometheus 采集指标，再用 Grafana 展示。不要把敏感的 Actuator 端点暴露到公网。

## 16. 缓存、异步、定时任务与消息

### 缓存

```java
@SpringBootApplication
@EnableCaching
public class DemoApplication { /* ... */ }
```

```java
@Service
public class ProductService {

    @Cacheable(cacheNames = "products", key = "#id")
    public Product get(Long id) {
        return repository.findById(id).orElseThrow();    // 只有缓存未命中才会执行
    }

    @CacheEvict(cacheNames = "products", key = "#id")
    public void update(Long id, ProductUpdate update) {
        // 修改数据后，让对应的缓存失效
    }
}
```

默认使用内存缓存。生产环境添加 `spring-boot-starter-data-redis` 和 `spring.cache.type=redis`，并为缓存设置过期时间。

### 异步与定时任务

```java
@Configuration
@EnableAsync
@EnableScheduling
class AsyncConfig {}

@Service
public class NotificationService {

    @Async                  // 在另一个线程执行，调用方不用等待
    public CompletableFuture<Void> sendWelcomeEmail(String to) {
        // 发送邮件...
        return CompletableFuture.completedFuture(null);
    }

    @Scheduled(cron = "0 0 2 * * *")      // 每天凌晨 2 点
    public void dailyCleanup() {
        // 清理过期数据
    }
}
```

如果你的应用部署了多个实例，`@Scheduled` 会在每个实例上都执行一次，需要用分布式锁（例如 ShedLock）来保证只执行一次。

### 调用外部 HTTP 服务

```java
import org.springframework.web.client.RestClient;

@Configuration
class HttpConfig {
    @Bean
    RestClient paymentClient(RestClient.Builder builder) {
        return builder.baseUrl("https://payments.example.com").build();
    }
}

@Service
class PaymentGateway {
    private final RestClient client;
    PaymentGateway(RestClient paymentClient) { this.client = paymentClient; }

    PaymentResult charge(ChargeRequest request) {
        return client.post()
            .uri("/charges")
            .body(request)
            .retrieve()
            .body(PaymentResult.class);
    }
}
```

**务必为外部调用设置连接和读取超时，** 并考虑重试与熔断（例如 Resilience4j），否则一个慢的下游服务会拖垮整个应用。

### 消息队列（Kafka 概览）

当一个操作需要通知多个系统，或要削峰解耦时，使用消息队列。

```java
@Service
class OrderEvents {
    private final KafkaTemplate<String, String> kafka;
    OrderEvents(KafkaTemplate<String, String> kafka) { this.kafka = kafka; }

    void publishPlaced(long orderId) {
        kafka.send("orders", String.valueOf(orderId), "PLACED");
    }
}

@Component
class BillingListener {
    @KafkaListener(topics = "orders", groupId = "billing")
    void onOrder(String message) {
        // 处理消息。消息可能被重复投递，所以处理逻辑必须是幂等的
    }
}
```

**设计规则：** 消息可能重复，消费者必须幂等。要保证“写数据库”和“发消息”一致，可以使用事务性发件箱（Outbox）模式。
