## 2. 分档与动作

### A 档：重写正文（browser / js / react，39 篇）

按三层重组，每篇 3,000+ 字，统一骨架：

1. 机制/原理（不是"是什么"，而是"为什么这样"）
2. 可运行代码或可抄的配置
3. 常见坑表（**现象 / 根因 / 解法** 三列）
4. 勾选式验收清单（6–7 条，都可当场验）
5. 练习（每题带"自检"标准）

### B 档：补结构（algo / nextjs / node）

正文不动，做三件事：

- 总览加三层地图 + 四类起点读法 + 每层验收标准；
- 补**练习与解答**（algo：限时模拟 + solutions；nextjs：每篇 2–3 题）；
- 补"能力清单 + 自测 10 题"作为毕业标准。

### C 档：只补阶段层（docker / python / higress / java / ruoyi）

正文已厚，只需：

- 总览加三层地图（现有篇目归类）；
- 每层给验收标准；
- java 补 1 篇独立毕业项目篇；ruoyi 补阶段划分说明。
